# Measurement discipline

ARBITER provides deterministic resonance/coherence measurement. Its outputs do not state empirical likelihood, moral correctness, factual certainty, or operational permission.

1. **Candidate completeness:** submit the real candidate universe in one request. Do not repeatedly ask with subsets then combine scores; that changes the problem being measured.
2. **Query structure:** role/context → state → constraints → disruptions → objective. Include perspective explicitly when it matters.
3. **No generated rationale:** the endpoint does not produce an explanation. Other systems may discuss the supplied facts, but must not attribute fabricated rationales to ARBITER.
4. **No score threshold assumption:** negative coherence scores are valid. Never label `0.74` as 74% confidence.
5. **Embedding parity:** operators have validated consistency of `/embed` and `/compare` ranking in controlled tests; do not recreate `/compare` with arbitrary cosine similarity.
6. **Action guard:** authorization, safety policies, API permission, and side-effect review are downstream checks.
7. **No kernel changes:** installing this skill changes client-side instructions and optionally serves public static documentation; it must never modify ARBITER's computation.
